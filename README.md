# 분리배출 지구 지킴이

만 5세~초등 2학년이 태블릿에서 하는 분리배출 학습 게임입니다.

- 놀이 주소: https://windylululu.github.io/eco-sort-game/
- 리더보드 바로 열기(교실 TV용): https://windylululu.github.io/eco-sort-game/#leaderboard

## 놀이 방법
1. 첫 화면에서 반과 동물 별명을 고릅니다.
2. 단계를 고릅니다(1단계 통 3개, 2단계 통 4개, 3단계 통 7개).
3. 물건을 알맞은 분리배출 통으로 끌어다 놓습니다. 맞히면 나뭇잎을 받습니다.
4. 반별 나뭇잎은 리더보드에 실시간으로 쌓입니다.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체 |
| `main.png`, `stage.png` | 첫 화면, 단계 고르기 화면 그림 |
| `firebase-config.js` | 파이어베이스 웹 설정값(공개용 값) |
| `firestore.rules` | 파이어스토어 보안 규칙(기록 추가·읽기만 허용, 고치기·지우기 금지) |

## 저장하는 것
반, 동물 별명 이모지, 단계, 나뭇잎 수, 틀린 물건, 날짜만 저장합니다. 학생 이름·사진·연락처는 저장하지 않습니다.
